# Mission Flag 🚩

**Mission Flag is a closed, Double Good-inspired spirit-flag fundraising platform with a separate approved-distributor wholesale channel.** A central Shopify store handles guest checkout, while Mission Flag manages partner access, 12 mascot/color-based design styles, campaign sharing, payouts, and production/fulfillment.
